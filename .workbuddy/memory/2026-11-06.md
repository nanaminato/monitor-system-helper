## 关键约束（务必记住）

- 本项目**不使用 XML 资源**：`build.ps1` 只用 aapt2 编译 manifest，没有 res 目录。所有 UI 必须代码构建，
  不要新增 `app/src/main/res/**` 或 `@style/...` 引用，否则 PowerShell 构建路径会失败。
- Kotlin 坑：在 `listView.apply { setAdapter(adapter) }` 里，`adapter` 会解析成 View 自身的
  `getAdapter()`（此时为 null），从而选中 `ListView.setAdapter(ListAdapter)` 重载，运行期抛
  "For ExpandableListView, use setAdapter(ExpandableListAdapter)"。必须写 `this@MainView.adapter`。
- 验证方式：`./gradlew.bat :app:assembleDebug` + `adb install -r` + `adb exec-out screencap -p`（本机
  `screencap -p /sdcard/x.png` 在该三星设备上不可用）。设备 R5CY12JN9DB；`adb shell cmd uimode night yes/no/auto`
  可切换深色模式做双主题校验。
